A stopped local install has a start shortcut on its rail entry. Its page is four tabs saying they need a running container, and the button that changes that was on the install tab; now a play icon sits on the entry itself, under This machine, on any install with a container to start. The icon is Lucide's, the set T3 Code draws from, which brings `lucide-react` into the console. It opens the install's page and starts the same run the install tab does, so the output lands there as always.
