A deployment can be reached from the companion over Tailscale, paired with a one-time code. A `remote` block on the root config picks the arm: a `tailscale/tailscale` sidecar beside the container, or the machine's own Tailscale serving a loopback port. `phoebe init` scaffolds the two Compose overlays and Serve's config, `phoebe start` adds the arm's overlay and reconciles Serve on the host arm, and the bootstrapper serves an open descriptor and a bearer-only `/api` with the report, an event stream, config edits, secrets and doctor runs. `phoebe pair` mints the code as root through a file drop; `phoebe sessions` lists and revokes the 30-day sessions the deployment keeps on its volume. The companion's rail lists machines, with a section per remote host, a deployment reachable two ways shown once per route, an add-remote modal that takes the pairing link, a devices panel, and pairing from the install tab. `docs/remote.md` is the whole of it. The companion opens a remote's console from its row, fed by `GET /api/logs`. The bootstrapper keeps its last lines in memory, pipes its children through so it sees theirs, and redacts every secret it has held and every token shape it knows before a line leaves the deployment. The remote page's overview carries Stop and Start for the fleet over `POST /api/fleet/stop` and `/api/fleet/start`. Every pipeline drains and the hold persists in `state/fleet-stop.json`, with the container and the API up so Start can undo it. The report's `bootstrapper.stopped` says who asked and when. The remote page's Session card carries Pair again, which takes a new code's scopes and ends the old session on the deployment, and Remove, which asks first and then drops the row and ends the session. A remote's rail row is drawn as a local row is, with the host's mark, the fleet's pause and start as its shortcuts when the session has `operate`, and a workspace's tenants under a chevron, each opening the console on that tenant's lines.
