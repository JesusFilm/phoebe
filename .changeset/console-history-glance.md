The console's overview tab opens with a card for the last 7 days: units, units a day, cost, and how many did not complete. The card reads the report's history summary. Under it, "Needs a look" lists up to six units from the week that did not complete. Each one opens the unit drawer, and a link opens the History tab. On the pipelines tab each row shows its last 7 days and opens into a 24-hour and 7-day breakdown, with the first pipeline open. A pipeline whose units reported no cost reads "tokens only".
