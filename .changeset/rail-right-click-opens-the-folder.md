A right-click on an install or a tenant in the companion's rail now offers Open folder and Open in terminal. The first opens the folder in the file manager, the second starts a shell in it: a console window on Windows, Terminal on macOS, and on Linux the terminal `$TERMINAL` names, or the first of the usual ones that is installed. A WSL install's shell opens inside its distro, at the path the distro knows. The desktop bridge's menu request gains a `folder` kind and two choices to go with it.
