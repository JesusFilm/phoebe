The console's rail reads more like T3 Code's project list. Every entry, a local install or a relay deployment, carries an icon for where it runs, a laptop for this machine, a terminal for a WSL distro, a cloud for a relay, and a settings gear at its edge that opens the install tab or the deployment's config. A workspace root opens out: a chevron before its name lists the children under it, found the way the bootstrapper finds them, each with a mark and a word read off the latest report (working, waiting, idle, held, wedged, or not in the fleet), and a child opens the workspace's pipelines tab.
